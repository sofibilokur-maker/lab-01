# findex

Проєкт для побудови текстового індексу корпусу книг.

Порівнюються два підходи до обробки тексту:

- Streaming — потокова обробка за допомогою генераторів.
- Greedy — обробка даних із використанням списків.

## Таблиця вимірювань

| Показник | Streaming | Greedy |
|---|---:|---:|
| Кількість документів | 136 | 136 |
| Кількість унікальних термінів | 175980 | 175980 |
| Час виконання, сек | 27.3185 | 18.0226 |
| Пікове використання пам'яті, MB | 93.08 | 543.17 |

## Висновок

Streaming використовує генератори для потокової обробки документів.

Greedy використовує списки для зберігання даних під час обробки.

За результатами вимірювань можна порівняти час виконання та використання оперативної пам'яті двох підходів.
